### 2. SecureBank — Bank Management System

An academic web development project created for a college project, demonstrating authentication, database integration, and banking-style workflows. This is a demonstration application, not a real banking service.

**Implemented and tested features:**
- User registration and login.
- Logout and authenticated access.
- Interactive dashboard.
- Account information and balance retrieval.
- Fund transfer module with recipient validation.
- Transfer processing through a Supabase database function (RPC).
- Row Level Security (RLS).

Additional modules, including transaction history, bill payments, fixed deposits, loans, cards, profile management, and customer support, are being developed or integrated.

**Tech Stack:** HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons, Supabase Authentication, PostgreSQL, Supabase JavaScript Client.

### 4. Smart Guard Helmet Module

**Hardware features built and tested:**

- Sensor-based accident monitoring.

The project combines electronics, sensors, embedded programming, and communication technologies to support rider safety.

**Tech Stack:** ESP32, Embedded C/C++, Sensors, IoT, GPS/GSM, Hardware-Software Integration.
